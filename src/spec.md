# Approved offline LEGO search

Deliver project-root index.html, containing all CSS, classic JavaScript, source records,
category/thesaurus data, and data-URI PNGs. No publication, network, CDN, account, or runtime fetch.
The approved user plan in this chat is the specification. Source Excel files are read-only.
AND across query/colour/category/size; single selection per facet; category descendants included.
Counts omit their own facet, retain query and other facets, and count unique TG records.
Colour components and transparency normalization preserve fine hues. Unknown measurements stay null.
Controlled concepts win over identical keywords; longest phrases precede shorter concepts.
Name and explicit keywords are fallback text; notes/model roles are not searchable.
Related category navigation replaces category, clears query and retains colour/size.
Acceptance cases are recorded independently in test_engine.cjs. Browser review uses the exported
file itself and a temporary local preview. Close the owned preview server after verification.
